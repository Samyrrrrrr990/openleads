OpenLeads documentation

Install OpenLeads, describe who you want, and send your first campaign from your own machine. Then go deep on how the engine finds and verifies every address.

Ten minutes to your first leads

One install, one sentence. OpenLeads searches the sources that fit and labels every email as found, pattern or guessed.

Open the quickstart 
pip install "openleads[all]"
openleads find "dentists in Austin"
openleads web
