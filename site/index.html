    Deliverability

    Checks that work without port 25.

    Most free finders rely on one SMTP probe that home ISPs block. When it fails, every address quietly becomes a guess. OpenLeads cross-checks seven signals instead.

    Seven independent signals

    Most of them need no port 25 at all.

    • MX consensusTwo DNS-over-HTTPS resolvers must agree
    • SPF, DMARC, and providerTXT record lookups
    • Disposable, role, and free-mail filtersStatic lists, checked locally
    • Gravatar existenceA real profile means a real inbox
    • Published addressesHarvested from commits and security.txt
    • Learned domain patternsImprove with every run
    • SMTP RCPT and catch-allDouble-probed when port 25 is open

    FAQ

    Questions people ask.

    Something missing? Open an issue

    Is it really free? What is the catch?

    The engine only uses free public sources and your own mailbox, so there is nothing to meter. The code is AGPL-3.0. If you want to build it into a closed-source product, there is a commercial license.

    How accurate are the emails?

    Every address is labeled: found (published somewhere), pattern (matches the company's known format), or guessed. The nightly benchmark publishes how many of each we return, so you can check before you trust it.

    Will this get my domain flagged?

    Only safe-tier addresses are sent by default. Sends are throttled and capped during warmup, every email has one-click unsubscribe, and the preflight grades SPF, DKIM, and DMARC before the first send. Use a secondary domain for cold outreach.

    Is this legal?

    It depends on where you and your recipients are. OpenLeads ships suppression lists and one-click unsubscribe headers, and the responsible use guide covers CAN-SPAM, GDPR, and CASL. It is built for relevant, low-volume outreach, not bulk spam.

    How is it like n8n?

    Recipes are workflows: a trigger, a search, a verify step that branches on the result, then write, send, and export nodes. The dashboard draws them as a canvas you can edit and run. You can also push leads into n8n or Zapier with the webhook export.

    Do I need to know Python?

    No. Install it with one command, or run npx openleads and type what you want in plain English. Python only matters if you want to add your own source.

    Install in one line.

    Python 3.8 or newer. The npx wrapper runs the same CLI.

    # the engine and the local app pip install "openleads[all]" # describe who you want openleads find "marketing agencies in Miami" # or open the local dashboard openleads web
    # no install, wraps the Python CLI npx openleads find "rust developers in Berlin" # chat mode: just type what you want npx openleads # add your own source cp lawyers.py ~/.openleads/sources/
    # add OpenLeads to Claude Code as an MCP server claude mcp add openleads -- openleads mcp # then ask in plain English find 20 accountants in Toronto and label their emails
