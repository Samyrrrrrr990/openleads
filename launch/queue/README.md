# Paste queue

Posts for Reddit, Hacker News and LinkedIn, ready to paste. One file per day,
`YYYY-MM-DD.md`, written alongside that day's work. Samyar reads each one, edits it
into his own words if needed, and posts it himself. Reply to comments by hand too.

Nothing in this folder is ever posted automatically. Those sites ban automated
posting, and the accounts are needed for the launches.

Before posting to a subreddit, read its rules. One subreddit per day at most.
